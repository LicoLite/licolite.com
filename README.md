# meshrix.io

Official product website for [Meshrix](https://github.com/LicoLand/Meshrix), an open-source, private-deployable agent gateway.

## Structure

```text
meshrix.io/
├── index.html                         # Product introduction page
├── styles.css                         # Calm technical layout system
├── CNAME                              # GitHub Pages custom domain
└── assets/
    ├── favicon.svg                    # Square slash favicon
    └── hero-mesh.svg                  # Hero mesh diagram
```

## Development

```bash
python3 -m http.server 8090
# Open http://localhost:8090
```

## Deployment

The site is published with GitHub Pages from the `main` branch root at <https://meshrix.io>.

The root `CNAME` file binds the Pages site to `meshrix.io`. Set `meshrix.io` as the custom domain in the repository's Pages settings and point the DNS records at GitHub Pages from the DNS provider. GitHub Pages redirects `www.meshrix.io` to the configured apex domain after both names resolve correctly.

For takeover protection, verify `meshrix.io` in the LicoLand organization Pages settings and add the exact TXT record generated by GitHub. The verification token is intentionally not stored in this repository.
