# licomesh.com

Official product website for [LicoMesh](https://github.com/LicoLand/LicoMesh), an open-source, private-deployable relay gateway platform.

## Structure

```text
licomesh.com/
├── index.html                         # Product introduction page
├── styles.css                         # Calm technical layout system
├── CNAME                              # GitHub Pages custom domain
└── assets/
    ├── favicon.svg                    # Square slash favicon
    └── hero-mesh.svg                  # Hero mesh diagram
```

## Development

```bash
python3 -m http.server 8090
# Open http://localhost:8090
```

## Deployment

The site is published with GitHub Pages from the `main` branch root at <https://licomesh.com>.

The root `CNAME` file binds the Pages site to `licomesh.com`. Set `licomesh.com` as the custom domain in the repository's Pages settings and point the DNS records at GitHub Pages from the DNS provider. GitHub Pages redirects `www.licomesh.com` to the configured apex domain after both names resolve correctly.

For takeover protection, verify `licomesh.com` in the LicoLand organization Pages settings and add the exact TXT record generated by GitHub. The verification token is intentionally not stored in this repository.
