# licomesh.com

Official product website for [LicoMesh](https://github.com/LicoLand/LicoMesh), an open-source, private-deployable relay gateway platform.

## Structure

```text
licomesh.com/
├── index.html                         # Product introduction page
├── styles.css                         # Calm technical layout system
├── CNAME                              # GitHub Pages custom domain
├── assets/
│   └── favicon.svg                    # Square slash favicon
└── dns/
    └── cloudflare-github-pages.txt    # Cloudflare BIND import for GitHub Pages
```

## Development

```bash
python3 -m http.server 8090
# Open http://localhost:8090
```

## Deployment

The site is published with GitHub Pages from the `main` branch root at <https://licomesh.com>.

The root `CNAME` file binds the Pages site to `licomesh.com`. Before importing DNS records, set `licomesh.com` as the custom domain in the repository's Pages settings. Then import [`dns/cloudflare-github-pages.txt`](dns/cloudflare-github-pages.txt) from Cloudflare's DNS records page.

The import contains GitHub's current apex `A` and `AAAA` records plus a `www` CNAME to `licoland.github.io`. Every imported web record is explicitly DNS-only. GitHub Pages redirects `www.licomesh.com` to the configured apex domain after both names resolve correctly.

For takeover protection, verify `licomesh.com` in the LicoLand organization Pages settings and add the exact TXT record generated by GitHub. The verification token is intentionally not stored in this repository or represented by a placeholder DNS record.
