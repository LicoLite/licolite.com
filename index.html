LicoMesh principles

P

Private deployment

Run the server in infrastructure you control. Core state remains under the selected server data directory.

O

Open by design

Source, protocol contracts, and extension boundaries stay visible so the platform can be inspected and adapted.

Connected through permission

Discovery and execution follow the same operation catalog, grants, policy evaluation, and approval path.

I

Integrated with boundaries

Optional services and plugins connect through declared contracts instead of becoming hidden runtime dependencies.
