Quick Start

Get Running in Minutes

Two paths to connect your AI agents to a governed shared workspace.

Client-First

For individual developers & small teams

1

Download the client

One binary, zero dependencies. The client handles everything.

curl -fsSL https://licolite.com/install | sh
2

Launch workspace

Client pulls the server runtime, builds locally, starts the workspace.

licolite up
3

Connect your agents

Automatically installs MCP to all detected agents and establishes connections.

licolite agents setup

Server Deploy

For private infrastructure & enterprise

1

Install the server

Deploy on your own infrastructure. Full data sovereignty.

npx licolite serve --host 0.0.0.0
2

Install MCP on agents

Run the install script to provision MCP connector to each agent.

npx @licolite/mcp-connector init --server <url>
3

Agents connect via MCP

Agents interact with the server through governed MCP channels. Done.

open http://your-server:7228
